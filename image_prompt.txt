PANTAU — Landing Page Image Prompts
=====================================

Tujuan: gambar-gambar berikut akan ditempel ke landing page (templates/core/landing.html,
static/core/css/landing.css) sebagai elemen visual, bukan sebagai foto sungguhan orang/instansi.
Semua prompt dirancang supaya BLEND IN dengan bahasa desain situs yang sudah ada (lihat "STYLE GUIDE"),
bukan tampil sebagai stock-photo generik yang menonjol.

STYLE GUIDE (wajib dipakai di setiap prompt generation)
--------------------------------------------------------
- Mood: data intelligence / command-center, tenang, presisi, terpercaya — bukan playful, bukan corporate stock-photo klise.
- Palet warna WAJIB: deep navy ink (#091d30, #122d43), teal (#0b8d8d), mint/teal terang (#31d6bd),
  warm off-white paper (#f5f5f0). Aksen putih untuk highlight. Hindari warna selain palet ini
  (tidak ada merah/oranye mencolok, tidak ada gradient pelangi).
- Tipografi di UI nyata: Archivo (heading, geometris, tegas) dan IBM Plex Sans (body). Jika gambar
  memuat elemen teks/label UI dummy, gunakan sans-serif geometris sejenis — TAPI sebisa mungkin
  hindari teks yang harus terbaca (biar aman dipakai di berbagai ukuran).
- Bentuk visual: garis tipis (hairline), grid/peta abstrak, node-and-edge network graph, chart/line
  sederhana, radar/heatmap wilayah Indonesia, sudut tajam bukan bulat (border-radius kecil, situs ini
  memakai radius 3–9px saja), banyak whitespace/negative space.
- Tekstur: flat design dengan sedikit depth (soft glow/blur radial ala .glow di CSS, subtle grain
  opsional), BUKAN 3D render mengkilap, BUKAN ilustrasi kartun, BUKAN foto orang kantoran generik.
  Referensi rasa visual: dashboard fintech/enterprise SaaS modern gelap (mis. Linear, Vercel, Stripe
  dashboard-style abstract art), disesuaikan ke tema social listening/media monitoring Indonesia.
  Boleh menyinggung motif Indonesia secara halus (kontur peta kepulauan, batik-line sangat minimal)
  tapi tetap abstrak, jangan dekoratif berlebihan.
- Framing: selalu beri ruang kosong (negative space) di salah satu sisi karena gambar akan
  ditumpuk dengan teks/tombol lewat CSS. Jangan taruh elemen penting persis di tengah kalau
  gambar akan dipakai sebagai background section.
- Aspek rasio & resolusi disebutkan per prompt di bawah. Ekspor sebagai PNG (butuh transparansi)
  atau JPG (gambar solid tanpa transparansi), sesuai catatan tiap item.
- Setelah digenerate, simpan file ke: static/core/img/<nama-file-di-bawah>

CATATAN INTEGRASI
------------------
- Simpan semua file hasil generate ke: static/core/img/
- Setelah gambar tersedia, beri tahu saya nama file yang dipakai supaya saya bisa menyambungkan ke
  landing.html / landing.css (background-image, <img>, atau og:image meta tag).
- Jika hasil generate meleset dari palet warna (terlalu terang/gelap atau warna di luar
  navy-teal-mint-paper), minta revisi dengan menegaskan ulang kode warna hex di atas — kebanyakan
  tools image-gen lebih akurat kalau hex code disebut eksplisit di prompt.
